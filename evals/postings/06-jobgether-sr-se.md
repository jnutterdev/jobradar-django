Title: Sr. Software Engineer (PHP + React/Typescript)
Company: Jobgether
---

This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for a Sr. Software Engineer (PHP + React/TypeScript) based in the United States.

As a Senior Full-Stack Software Engineer, you will build and improve digital tools that help nonprofit organizations manage fundraising events, including galas, auctions, and live experiences. You will own solutions from initial problem discovery through production delivery, working across React and TypeScript interfaces, PHP services and APIs, and the underlying data architecture. The role has a stronger frontend focus while requiring the ability to contribute confidently across the full stack. You will collaborate closely with Product, QA, and mobile engineers to deliver complete, reliable customer experiences. Working in an environment where requirements are not always fully defined, you will exercise sound judgment, take ownership, and drive problems through to resolution. AI coding tools are an integral part of the development workflow, and you will help raise engineering quality and productivity through thoughtful adoption, testing, and review.

Accountabilities

End-to-End Feature Ownership: Shape technical approaches, build React interfaces, develop PHP services and APIs, design data changes, test solutions, and safely release features behind feature flags.
Problem Solving: Identify the underlying customer problem behind requests, navigate ambiguity, communicate assumptions, and drive solutions through to meaningful resolution.
AI-Assisted Development: Use AI coding tools such as Claude Code for everyday coding, debugging, research, and code review, applying engineering judgment to validate generated output and distinguish reliable fixes from plausible but incorrect suggestions.
Engineering Quality: Build quality into every delivery through unit, component, Storybook, Playwright, and PHPUnit tests, and contribute to thoughtful, constructive code reviews.
Production Reliability: Investigate production issues using logs, Sentry, and system-level knowledge, identify root causes, and implement fixes that prevent recurring problems.
Cross-Functional Collaboration: Work closely with Product, QA, and mobile engineers responsible for iOS and Android terminals, communicating technical decisions and tradeoffs clearly.
Technical Ownership: Consider the wider impact of changes across connected systems, take responsibility for testing, rollout, and follow-up, and communicate potential delivery risks early.
Technical Leadership and Mentorship: Influence technical direction as a senior engineer, mentor colleagues, provide useful code reviews, document knowledge, and help teammates improve their work.
Continuous Improvement: Adapt quickly to new projects and technologies, adopt effective development practices, and continuously improve the quality and speed of software delivery.

Requirements

Deep, recent professional experience building production applications with React and TypeScript, including state management using Redux Toolkit or similar tools.
Strong, recent professional experience with PHP; PHP is a required skill, with PHP 8.x preferred.
Daily, hands-on experience using AI coding tools such as Claude Code or GitHub Copilot, including effective prompting, providing context, and critically validating AI-generated code through testing and review before release.
Strong modern web development fundamentals, including accessible and responsive interfaces, Tailwind or utility-first CSS, and reusable component design.
Strong SQL and relational database knowledge, particularly MySQL, including query design and performance optimization.
Solid understanding of REST API design, asynchronous and queue-based processing, caching with Redis, production debugging, and observability.
Experience with automated testing across the application stack, including tools such as Vitest or Jest, React Testing Library, Storybook, Playwright, and PHPUnit.
Ability to make progress when requirements are incomplete, ask effective questions, communicate assumptions, and consider the broader impact of technical decisions.
Strong ownership and organizational skills, including the ability to manage commitments, communicate delivery risks proactively, and follow work through completion.
Adaptability and willingness to learn new technologies, work across projects, and adopt improved development practices.
Coachability, openness to feedback, sound technical judgment, and a commitment to maintainable, high-quality code.
Experience operating as a senior engineer within a team and influencing technical direction without formal management authority.
Strong collaboration, mentoring, documentation, and communication skills.

Nice To Have

Experience with Twig, Psalm, PHPStan, or other modern PHP development tools.
Real-time web development experience, including Server-Sent Events (SSE), WebSockets, or live-event and auction systems.
Payments development or PCI-aware engineering experience.
Familiarity with AWS services such as SQS, Kafka, and S3.
Experience with Docker-based local development environments.
Familiarity with native mobile development using Swift or Kotlin.
Experience with CRM systems or nonprofit and fundraising platforms.
