We're building the future of legal services.

Modern Family Law, a fast-growing national law firm specializing in family law, is seeking a Senior Frontend React Engineer.

We are building a new technology product for family law, where the quality of the user experience matters because clients and attorneys will rely on it for real legal workflows. This is a greenfield build integrating enterprise systems, payments, data and AI capabilities, and the frontend architecture established in this role will support the product as it grows.

What You Will Own

Own the frontend architecture and implementation of the product in React and TypeScript, from shared components and application structure through production workflows.
Translate product designs and interactive prototypes into production-ready user experiences, working closely with product and backend engineers to align design, workflow, and data requirements.
Own frontend patterns for complex multi-step workflows, including forms, conditional logic, validation, autosave, resume, loading states, error handling and recovery.
Partner with the Senior Backend API Engineer to define API contracts, data structures, error handling and clear client/server responsibilities.
Establish component architecture, state-management patterns, routing, form strategy and frontend conventions that support a maintainable application.
Build secure, role-aware experiences for clients and attorneys, with strong validation, clear user feedback, and accurate presentation of permissions and workflow state.
Integrate AI-powered capabilities into product workflows, including how generated content, sources, confirmations, corrections, loading states and failures are presented to users.
Own frontend performance, accessibility, responsive behavior, browser support and production quality throughout development.
Establish testing practices for critical components and user workflows, including component, workflow and regression coverage.
Review code, set frontend standards and provide technical guidance to the existing frontend developer as the team grows.

The Stack

Client application

React and TypeScript.

Build tooling

Vite.

Frontend architecture

Component architecture, application state, routing, forms, validation, error handling, and reusable design patterns.

API integration

The frontend integrates through API contracts owned by the Senior Backend API Engineer, working closely with the Senior Backend Platform Engineer on the underlying domain services and application data.

Identity and security

Role-aware experiences and secure handling of sensitive client information. Backend services are authoritative for authentication and authorization enforcement.

AI-enabled Experiences

The product incorporates AI, retrieval and knowledge services. You do not need to be an ML engineer, but you should understand how to design clear, reliable interfaces around AI-enabled workflows.

Quality

Accessibility, performance, responsive behavior, browser compatibility and automated frontend testing.

Requirements

Minimum Qualifications

You must reside within a commutable distance to one of our GA or TX offices (Atlanta, GA, Alpharetta, GA, Savannah, GA, Dallas, TX, and Austin, TX)
Production experience building React and TypeScript applications with complex user workflows.
Experience establishing frontend architecture for products with meaningful application state and significant integration with backend services.
Strong knowledge of component architecture, state management, forms, routing, and maintainable frontend patterns.
Experience building multi-step or workflow-based applications with validation, conditional logic, persistence, recovery, and clear error states.
Understanding of frontend authentication flows and role-aware interfaces, including which controls must be enforced by backend services.
Experience partnering with backend engineers to define API contracts and data structures.
Strong accessibility, responsive design, browser compatibility, and frontend performance practices.
Experience implementing automated frontend testing for critical components and user workflows.

Ability to work independently as the Senior Frontend React Engineer on a greenfield product and make sound architectural decisions.

Experience building payment, client intake, or other state-sensitive workflows.
Experience working with sensitive client data or in a regulated environment.

Legal industry or legal technology experience.

Characteristics of the Ideal Candidate

The ideal candidate is a systems builder who enjoys solving complex operational problems through thoughtful engineering and intelligent automation.

They are highly organized, technically curious, operationally minded, and energized by the opportunity to help redesign legal service delivery through scalable AI infrastructure and workflow systems.

This individual should possess the ability to:

Think architecturally and systematically.
Translate operational needs into scalable technical solutions.
Collaborate effectively across legal, operational, and technical teams.
Identify inefficiencies and design elegant workflow solutions.
Balance innovation, reliability, security, and operational scalability.
